# Diseñador de crochet

App web instalable para crear gráficos de crochet: vueltas circulares para círculos y esferas de amigurumi, y vueltas cuadradas para granny squares. Los gráficos usan símbolos de puntos, colores por vuelta y recuento orientativo.

Los proyectos se guardan en el almacenamiento local del navegador. Usa el mismo navegador y dispositivo para volver a verlos.
